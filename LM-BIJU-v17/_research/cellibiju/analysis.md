### 2.7 看起来贵的地方
1. **02 分类大图（x 75–1826, y 199–907）**：统一的白色鹅卵石 + 自然硬光 + 金饰，4:5 大图 567px 宽，产品占画面主体，材质高光清晰——整站最有"品牌"感的部分。
2. **01 Hero 摄影**：金色海螺耳环特写纹理细节好，全出血，色调（暖白 + 金）克制。
3. **大留白与高对比黑白**：#252525/#FFFFFF 15.33:1，区块间 160–210px 留白（03/04），不拥挤。
4. **暖灰页脚 #EFECEC（05）**：比纯灰温和，与石头背景色调呼应。

### 2.8 看起来便宜的地方
1. **01 公告条 "**ATENÇÃO**"**（y 0–56）：字面星号 + 大写"注意"，像论坛公告，语气是警告而非服务。
2. **01 头部 376px + 两行 10 项导航**：大 Logo 占据视觉中心，导航自动换行成两行且第二行只有 2 项（"ACESSÓRIOS DE LOJA / PROMOÇÕES"，y≈387），显得未规划；每项都带 ∨ 箭头，噪音多。
3. **Logo 本身（01 x 787–1107；04 左半）**：青绿 #83D8D0 + 几何无衬线 + 下划线，像通用快时尚/药妆标识，与金饰摄影色调不搭；04 又把同一 Logo 当 850px 宽插图重复放置，空占半屏。
4. **01 Hero 文字直接压在复杂石纹上**，无遮罩：副标题 ≈4.1:1，"Regi-s-te" 中的 "gis" 落在阴影上几乎不可读（01 x 650–760, y 795–825）。
5. **03 门店区**：每行地址单独成段、居中堆叠、用一排句点 "......" 作分隔线（x 815–1085, y 841）——文本编辑器式排版。
6. **07 登录页**：换成 Roboto + Material 投影按钮 + 全大写，主按钮 #828282 看起来像禁用态；与主题完全不同的视觉语言，暴露"插件拼装"。
7. **全站只有系统字体 + Regular 字重**：无展示字体、无字重对比，排版缺少奢华感所需的张力。
8. 语言选择器 "Português (portugal)" 小写国家名（01），细节不严谨。

## 4. 做得好
- **B2B 定位表达清楚（信息架构）**：首屏三处明确"批发/首单门槛/注册看价"（01 公告条 + H1 + 副标题），访客 3 秒内知道这不是零售站。
- **目标客户文案精准（04）**：直接点名 Instagram/Facebook 卖家、网店/实体店、新创业者，并给出注册、信息页、条款、联系内链。
- **面向复购的导航（06）**：Novidades 下分 "Nova Coleção / Reposição"，懂批发商补货习惯；另有店铺陈列与配件品类（01）。
- **信任（03/05）**：真实门店地址、营业时间、"Obter Direções"；页脚完整政策、支付图标、社媒。
- **视觉**：统一摄影风格与 4:5 大图（02）；黑白高对比文字（15.33:1）。
- **可访问性**：导航有明显键盘焦点框（06 x 172–350, y 303–363）；页脚链接 6.13:1。
- **实用帮助**：页脚 "Como medir com uma moeda"（05）、"Recomendações de uso"。

## 6. LM BIJU 可超越点 / 可持平点 / 做不了的

**可超越点**
- 视觉品牌：定制字体组合、可用于 UI 的品牌色、统一组件（含登录/注册），直接拉开 Cellibiju 的"Dawn 原样 + 插件拼装"感（对比 01 vs 07）。
- 首屏效率：紧凑头部（≤120px）+ 清晰价值主张 + 双 CTA，对比其 432px 头部（01）。
- 门禁体验设计：访客在 PLP/PDP 看到设计过的"Preço de revenda — inicie sessão"占位，而不是简单隐藏；注册页展示权益、审批时效、所需资料（NIF/IVA、店铺链接）。
- B2B 功能深度：单品 MOQ/包装倍数、分级价表、快速下单（SKU 列表/CSV）、RFQ 询价、再次下单——这些在 Cellibiju 截图中均未见（第 3 节）。
- 首页商品曝光：新品/补货轨道，对接其 "Reposição" 概念但做得更直接。
- 无障碍：表单 label、按钮对比度 ≥4.5:1（其 07 不合格）。

**可持平点**
- 统一摄影风格与 4:5 大图（02）——需要 LM BIJU 投入同等质量的产品拍摄，否则难以超越。
- 首单金额门槛的清晰告知（01）、政策页完整度、支付图标、社媒（05）。
- 面向经销商的品类（陈列道具、配件）——取决于 LM BIJU 实际货品。

**做不了的（或不确定能做）**
- 线下展厅（Porto Varziela / Lisboa，03）：若 LM BIJU 无实体展厅，这项信任信号无法复制，只能用仓库实拍、公司资质、客户评价替代。LM BIJU 情况 无法确认。
- 其摄影素材与品类广度：无法复制；SKU 规模 截图未覆盖，无法比较。
- 其实际转化/SEO/性能表现：无数据，无法判断是否需要"超越"。
