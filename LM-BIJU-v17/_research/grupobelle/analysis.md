## 2. 设计审美

### 2.1 气质关键词（3-5）
1. **暖米色棚拍**（石灰华/布料/干花影子；01、02、10、12、26）
2. **模板化 B2C 电商**（Bootstrap 灰阶 + 默认组件；17、23、30）
3. **金色装饰过量**（金色色块、金色标题、金色图标；02、03、05、09）
4. **风格拼贴**：几何粗体 + 手写体 + 斜体 + Inter 混用（01、05、13、14）

### 2.7 看起来贵的地方
1. **01 全屏 Hero**：暖米色石灰华、玛瑙片和干花投影，景深柔和，产品（葡式瓷砖珐琅）与本土文化叙事结合，摄影质量可以对标中高端品牌。
2. **02/10/12/13 图块摄影**：整站道具（石灰华、亚麻、玻璃皿）和光影方向统一，形成可辨识的品牌摄影语言，这是 Grupobelle 最值钱的资产。
3. **17/18 PLP 模特手部图**：奶油色西装 + 裸色美甲，色调统一，可信度高。
4. **28 Malabelle 横幅**：布幔 + 石台，三只包构图对称，属于杂志级棚拍。

## 6. LM BIJU 可超越点 / 可持平点 / 做不了的（及原因）

**可超越**
- 字体与色彩体系：衬线显示字体 + 无衬线正文，暖中性色阶，金色只做点缀（对手在 2.2/2.3 两项都失分）。
- 头部：单行、约 72–80px、不透明底、logo 为主。
- 图块标签：HTML 文本加底部渐变遮罩，或把说明放在图下，对比度 ≥4.5:1。
- PLP 的 B2B 化：分面筛选、卡片上显示 PVPR/登录看价/MOQ/箱规、每页数量可选、紧凑列表视图。
- 登录后功能：阶梯价表、SKU 快速下单/CSV 上传、RFQ 询价（对手全无，或截图未见）。
- PDP 结构化规格：尺寸、重量、镀层、防敏、包装数量。
- 注册流程：写明 B2B 权益，收集 NIF 和公司信息，告知审核时长。
- 语言一致与校对，去掉推送铃铛。

**可持平**
- 公开 PVPR 并隐藏批发价（19 的模式值得照搬）。
- 起步套装（Kit de Iniciação）和门店陈列耗材品类。
- 信任条（48h 发货、安全支付、客服）、本地支付图标、面包屑。

**做不了的（短期）**
- 3000m² 实体展厅和实景视频（04）：物理资产。
- 2008 年起的经营历史、自有工厂（06）：时间和产能积累。
- 大规模统一棚拍（数十组石灰华场景，01–29）：需要持续的摄影预算。LM BIJU 可以用少量高质量主视觉加统一白底规范来弥补，但做不到同等体量。
- SKU 规模（戒指 282、时尚配件 273、门店配件 216）：属于供应链层面的事。
