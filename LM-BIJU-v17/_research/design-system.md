# LM BIJU 设计系统 v3（深色版 + 白色版）

> 两个 Demo 共用同一套字号阶梯、间距、栅格和组件结构，只在颜色和动效上分开。
> 对比度都是用 WCAG 2.x 公式实际算出来的。计算脚本见本次提交记录，数值见下表。

## 1. 字体

| 角色 | 字体 | 用在哪里 | 字重 |
|---|---|---|---|
| 全站（标题、正文、UI、价格、SKU） | **Inter**（可变字体 400–700） | 所有文字 | 400 / 500 / 600 / 700 |
| 衬线辅助（仅深色版） | **Cormorant Garamond** 500（含斜体） | 只用在 Logo 和 ≥48px 的大标题 | 500 |

- **不再使用** Fraunces、JetBrains Mono，也不用其它有"作者感"的展示字体。
- **价格和 SKU** 用 Inter 加 `font-variant-numeric: tabular-nums`，不再单独加载等宽字体。实测 Inter 在 20px 下，tabular 模式里"1111"和"0000"都是 51.88px；比例模式里分别是 32.55px 和 50.47px。
- **白色版全部用 Inter**，Logo 也是 Inter 600 加宽字距。
- **葡萄牙语变音**：ã õ ç á é í ó ú â ê ô à 以及 € — – « » 都在 latin 子集（U+0000–00FF、U+2000–206F、U+20AC）里。已在浏览器里渲染验证，截图见 `_research/evidence/font-specimen-inter.png`，`document.fonts.check` 结果为 true。
- **文件**：`proposals/assets/fonts/`，本地托管，SIL OFL 1.1 许可证文件放在一起。
  - Inter latin 48 KB（葡语页面只会下载这一个）
  - Inter latin-ext 85 KB（只有遇到扩展字符才下载）
  - Cormorant latin 23 KB × 2（正体、斜体）
- **加载**：`font-display: swap`；首屏字体用 preload。回退字体栈：`Inter, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif`。

## 3. 间距与栅格
- **间距刻度（4 的倍数）**：`4 · 8 · 12 · 16 · 24 · 32 · 48 · 64 · 96 · 128`
- **区块节奏**：
  - 桌面端：上下 `clamp(64px, 10vw, 128px)`
  - 手机端：64px
- **栅格**：12 列。
  - 内容最大宽 1440px，左右留白 `clamp(16px, 4vw, 48px)`，列间距 24px（手机端 16px）。
- **头部**：单行，桌面端 72px、手机端 60px，吸顶。竞品是 150–432px。
- **圆角**：0，只有徽章用 2px。
- **阴影**：不用；层次靠底色和细线区分。

## 4. 组件规范

| 组件 | 规范 |
|---|---|
| idx 小标签 | 12px / 600 / 全大写 / 0.08em 字距；格式"01 — Coleções"；深色版用 --gold，白色版用 --accent-ink |
| 区块标题 | idx 小标签 + H2（48/32px）+ lede（18/16px，最多 60 字符宽） |
| 主按钮 | 48px 高，左右 24px 内边距，16px / 500；深色版为亮底深字，白色版为深底白字；悬停时底色加深，焦点环 2px |
| 次按钮 | 同尺寸，1px 边框用当前文字色，背景透明 |
| 文字链接 | 下划线偏移 4px；悬停时下划线变粗 |
| 产品卡 | 无边框；4:5 图片；图下依次为名称（16/500）、材质徽章 + SKU（tabular）、PVP、价格锁或阶梯起价；操作行是数量 + "+ Pedido"；悬停：深色版推近，白色版上浮 4px |
| 徽章 | 12px / 500 / 2px 圆角 / 1px 边框；"Novo""Foto temporária""Imagem ilustrativa gerada por IA" |
| 筛选 | 6 个维度用 `<select>`；"Limpar"；结果数量用 aria-live；网格 / 列表切换用 aria-pressed |
| 表单 | label 在输入框上方；输入框 48px 高，边框对比度 ≥3:1；错误用文字说明（不只靠颜色）；NIF 按校验位实时校验 |
| 阶梯价表 | `<table>` 加 caption；当前档位整行高亮，并用文字标出（"escalão atual"） |
| 手风琴 | 原生 `<details>` / `<summary>` |
| 进度条（询价） | `<ol>`，当前步骤用 aria-current="step" |
| 面包屑 | `<nav aria-label="Caminho">` |
| 图片 | `<picture>` 按 AVIF → WebP → JPEG 回退，写明 width 和 height，首屏以外用 loading="lazy" |
| AI 标注 | 每张 AI 图上都有"Imagem ilustrativa gerada por IA"（12px），对比度 ≥4.5 |

## 5. 动效

### 深色版（10 条，全部遵守 `prefers-reduced-motion`）
| # | 动效 | 时长 / 缓动 |
|---|---|---|
| M01 | Hero 标题逐行从遮罩中升起 | 900ms，expo.out |
| M02 | 图片视差，加 48 帧随滚动逐帧播放 | 跟随滚动 |
| M03 | 图片遮罩揭开（clip-path） | 1400ms，`cubic-bezier(.76,0,.24,1)` |
| M04 | 开场 1.5 秒：暗场、金线、品牌名，可跳过 | 1500ms |
| M05 | 数字从 0 滚到目标值 | 1400ms |
| M06 | Hero 里金色光晕跟随鼠标 | 480ms 缓动 |
| M07 | 章节"Nº 0X"从左侧滑入 | 900ms |
| M08 | 自定义光标（只在有鼠标的设备上启用） | 跟随 |
| M09 | 产品卡悬停时图片推近 1.04 | 480ms |
| M10 | 页面转场（View Transitions）；从首页进目录时"开灯"圆形展开 | 700ms |

### 白色版（4 条）
| # | 动效 | 时长 |
|---|---|---|
| L1 | 滚动淡入：12px 位移 + 透明度，每个区块只触发一次 | 480ms，ease-out |
| L2 | 图片遮罩揭开（inset 自下而上） | 900ms |
| L3 | 悬停轻微上浮：图片 translateY(-4px) | 240ms |
| L4 | 页面转场：View Transitions 交叉淡化；不支持的浏览器直接切换 | 240ms |

- 白色版**不用** GSAP、视差、3D 或自定义光标。
- 48 帧在白色版里改成**用户拖动的滑杆**来查看，不跟随滚动。

- 缓动：`--ease-out: cubic-bezier(.16,1,.3,1)`；`--ease-inout: cubic-bezier(.76,0,.24,1)`
- 时长刻度：`120 / 240 / 480 / 900 / 1400ms`

## 6. 图片规则
- **管道**：sRGB，去掉元数据，每张图输出 AVIF + WebP + JPEG，多个尺寸。清单在 `proposals/assets/manifest.json`，预览页是 `proposals/assets/preview.html`。
- **AI 图**：必须加标注，并且不冒充具体 SKU（不做产品图，只做氛围、场景、章节图）。
- **临时图**：没有实拍照片的 SKU，暂时用最接近的现有实拍照片，并加"Foto temporária"徽章。
- **有第三方品牌的图**（pendente-halo：EMIZA）：只作为编辑配图，标"Fotografia temporária"，不当作 LM BIJU 的商品。
- **首屏图（LCP）**：preload，加 `fetchpriority="high"`，不做透明度动画，只做 scale，保证 LCP 不被推迟。

## 7. 无障碍（WCAG 2.2 AA）
- 跳到正文的链接；语义化地标；一个页面只有一个 H1。
- 切换路由后把焦点移到新页面的 H1，并更新 `document.title`。
- 所有交互元素都能用键盘操作；焦点环 2px，偏移 3px。
- 触控目标 ≥ 24×24（主要控件 ≥ 44px 高）。
- 自动轮播可以暂停（2.2.2）。
- 关闭 JS 时，所有页面顺序展开，内容可读。
