# LM BIJU 新站 Demo · 演示指南（v3：深色版 + 白色版）

> 给你自己看的讲解稿：怎么打开、按什么顺序走、每页点什么、客户常问的问题怎么答。

## 1. 怎么打开

| 方式 | 适合 | 步骤 |
|---|---|---|
| **A. 离线包（推荐发给客户）** | 任何电脑，不需要网络和 Python | 解压 `lm-biju-demo-offline.zip` → 打开 `LM-BIJU-demo` → 双击 `index.html` → 选"Versão escura"或"Versão clara" |
| **B. 一键脚本** | 你的电脑，已装 Python 3 | Windows 双击 `start-demo.bat`；macOS / Linux 运行 `./start-demo.sh`。浏览器会打开选择页 |
| **C. 直接打开** | 已解压的离线包 | 双击 `demo-dark.html` 或 `demo-light.html` |

- 离线包**必须先解压**。
- 演示前把浏览器缩放设为 100% 并全屏（F11）。
- 深色版的开场动画每个标签页只播一次。想再看，关掉标签页重新打开。

## 2. 先给客户看哪一版？
- **先放白色版 30 秒，再切深色版**。白色版回答"这个网站好不好用"，深色版回答"这个品牌有没有质感"。
- 两版的页面和内容完全相同，客户只需要选风格。
- 选择页（`index.html`）上两版并排，可以当开场。

**首页 → Coleções → 分类页 → 产品详情 → 询价单 → 登录 / 注册 → 账户 → Empresa / Showroom**

## 4. 两版的区别
| | 深色版 | 白色版 |
|---|---|---|
| 气质 | 暗场、戏剧化，金色点缀 | 纯白、克制，大图、细线 |
| 字体 | Inter；Logo 和超大标题用 Cormorant | 全部 Inter |
| 动效 | 10 条：开场、标题逐行出现、视差、遮罩揭开、数字滚动、光晕、章节编号滑入、自定义光标、卡片推近、页面转场 | 4 条：淡入、遮罩揭开、悬停上浮、页面转场 |
| 48 帧视频 | 随滚动逐帧播放 | 拖动滑杆查看 |
| 手机 | 竖图 Hero，循环视频 | 大图在上，文字在下 |
| Lighthouse 手机性能 | 98（gzip） | 99（gzip） |

## 5. 客户常见问题：回答模板
**Q1. 价格是真的吗？**
不是。批发价和阶梯价是按 PVP 推算的示例；正式网站由后台按客户账户输出。
PT：*"Os preços desta demonstração são exemplos; no site final cada conta validada vê os seus preços e escalões."*

**Q2. 图片是 AI 生成的吗？**
氛围图是 AI 生成的，每张都标了"Imagem ilustrativa gerada por IA"。产品图都是你们现有的实拍照片。有 5 个 SKU 暂时用相近的照片顶上，标了"Foto temporária"。
PT：*"As imagens de ambiente estão identificadas; as fichas usam fotografias reais das peças."*

**Q3. 为什么"Ouro 18K"写成"Banho de ouro 18K"？**
现网站的产品描述都是镀层。单写"Ouro 18K"会被理解成实心金。需要你们确认。
PT：*"Escrevemos 'banho de ouro 18K' para não confundir com ouro maciço — confirmam?"*

**Q4. 能放到 WordPress 上吗？多久？**
可以：WooCommerce + 自定义区块主题 + B2B 插件（按角色显示价格、起订量、询价）。工期**推测**为设计定稿后 6–10 周，取决于 SKU 数量和数据导入方式。

**Q5. 手机上好用吗？**
两版在 390px 宽的手机上逐页测过：无障碍 0 问题，图片全部加载，没有横向滚动。

**Q6. 不喜欢动效的用户怎么办？**
系统开启"减少动态效果"后，所有动效自动关闭，内容一样完整。关闭 JavaScript 后页面也能按顺序阅读。

**Q7. 注册以后怎么审核？客户账户能做什么？**
正式版里，注册进入后台待审核，销售核对 NIF 后开通。账户里有订单、询价单、常购商品和一键补货，Demo 里用示例数据演示。

**Q8. 联系方式和数字是真的吗？**
956 / 486 / 342 / 128 这四个数字来自现网站。邮箱和营业时间也沿用现网站。WhatsApp 号码是占位，上线前替换。
